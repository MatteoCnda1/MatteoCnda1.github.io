# CCNP ENCOR (350-401)

> Certification **Cisco CCNP Enterprise — Core (ENCOR, examen 350-401)**, entièrement distincte du parcours CCNA. Six domaines : architecture d'entreprise, virtualisation, infrastructure (switching/routage avancé, multicast, WAN, wireless), assurance réseau, sécurité et automatisation/programmabilité.
