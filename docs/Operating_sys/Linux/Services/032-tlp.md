# tlp

**TLP** est un outil de gestion avancée de l'alimentation pour laptops sous Linux : il ajuste automatiquement des dizaines de paramètres (governor CPU, USB autosuspend, gestion PCIe ASPM, seuils de charge batterie...) selon que la machine est sur secteur ou sur batterie, pour maximiser l'autonomie sans intervention manuelle.

## Installation

```bash
# Debian/Ubuntu
sudo apt install tlp tlp-rdw

# Fedora
sudo dnf install tlp tlp-rdw

sudo systemctl enable --now tlp
```

`tlp-rdw` (Radio Device Wizard) active en plus la coupure automatique du WiFi/Bluetooth selon le contexte réseau.

## Fichiers de configuration

| Chemin | Rôle |
|---|---|
| `/etc/tlp.conf` (ancien) ou `/etc/tlp.d/*.conf` (moderne, fragmenté) | Configuration principale |
| `/usr/share/tlp/defaults.conf` | Valeurs par défaut (ne pas éditer, sert de référence) |

## Commandes utiles

| Commande | Fonction |
|---|---|
| `systemctl status tlp` | État du démon |
| `sudo tlp-stat` | Rapport complet de l'état énergétique courant |
| `sudo tlp-stat -b` | État spécifique de la batterie (santé, seuils de charge) |
| `sudo tlp ac` / `sudo tlp bat` | Forcer manuellement le profil secteur/batterie |
| `sudo tlp start` | Réappliquer la configuration immédiatement |

## Exemple de configuration

```ini
# /etc/tlp.d/01-battery.conf
CPU_SCALING_GOVERNOR_ON_BAT=powersave
START_CHARGE_THRESH_BAT0=40
STOP_CHARGE_THRESH_BAT0=80
```

Limite la charge entre 40 % et 80 % sur batterie (préserve la longévité de la batterie sur les modèles qui le supportent, notamment ThinkPad/Dell) et force le governor CPU en mode économie d'énergie hors secteur.

## Sécurisation

Pas d'enjeu de sécurité réseau direct. Points de vigilance opérationnels :

- TLP peut entrer en conflit avec `power-profiles-daemon` (installé par défaut sur GNOME/Fedora récents) si les deux tournent en même temps — désactiver l'un des deux (`systemctl mask power-profiles-daemon`) pour éviter des réglages qui s'écrasent mutuellement.
- Les seuils de charge batterie (`START/STOP_CHARGE_THRESH`) ne sont supportés que sur certains modèles (principalement ThinkPad) — vérifier `tlp-stat -b` pour confirmer que le matériel les applique réellement avant d'en dépendre.

## Logs & dépannage

```bash
journalctl -u tlp
sudo tlp-stat -s     # résumé système : mode actuel (AC/BAT), governor, conflits détectés
sudo tlp-stat -b     # diagnostic batterie
```

`tlp-stat` signale explicitly les conflits connus (ex: `power-profiles-daemon` actif) directement dans sa sortie — premier réflexe de diagnostic.
