# Phonétique

> Comment l'italien se lit et comment il se prononce : l'alphabet, les voyelles ouvertes et fermées, les **consonnes doubles** (qui changent le sens d'un mot), les sons durs et doux de `c` et `g` selon la voyelle qui suit, les groupes `gn`, `gli`, `sc`, et les règles d'**accentuation** tonique.
>
> La seconde fiche recense les **faux-amis** italien-français — nombreux et traîtres entre deux langues aussi proches — ainsi que les erreurs que commettent systématiquement les francophones : nasalisation, `u` prononcé à la française, accent sur la dernière syllabe, consonnes doubles ignorées.
