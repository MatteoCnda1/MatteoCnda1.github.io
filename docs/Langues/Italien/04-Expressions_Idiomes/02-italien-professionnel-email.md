# Italien professionnel et courriels

> L'italien professionnel est plus formel que le français à l'écrit : il conserve des formules qu'un francophone jugerait désuètes (*Distinti saluti*, *In attesa di un Suo cortese riscontro*) et emploie systématiquement le **Lei** de politesse, avec la majuscule aux pronoms et adjectifs qui s'y rapportent (*La ringrazio*, *il Suo messaggio*).
>
> Cette fiche donne les blocs à assembler : objet, ouverture, corps, demandes, clôture, plus les expressions des réunions, des appels téléphoniques et de l'entretien d'embauche.

## 1. Les règles de base du courriel italien

| Règle | Détail |
|---|---|
| **Vouvoiement en `Lei`** | Troisième personne du singulier, jamais *voi* (sauf à un groupe ou en registre commercial méridional). *Le scrivo per...* = Je vous écris pour... |
| **Majuscule de courtoisie** | `Lei`, `La`, `Le`, `Suo`, `Sua`, `Vi`, `Vostro` prennent la majuscule dans un courrier formel. |
| **Titres obligatoires** | On utilise le titre professionnel : *Dottore*, *Ingegnere*, *Avvocato*, *Professore*. Toute personne diplômée de l'université est *Dottore / Dottoressa*. |
| **Abréviations courantes** | *Egr.* (Egregio), *Gent.* (Gentile), *Spett.le* (Spettabile), *Dott.*, *Ing.*, *Avv.*, *Prof.*, *Sig.* (Signore), *Sig.ra* (Signora). |
| **Ton** | Plus cérémonieux qu'en français : les formules de gratitude et d'attente sont attendues, pas facultatives. |
| **Cordiali saluti** | Formule neutre passe-partout ; *Distinti saluti* est plus froid et plus formel. |

| Élément du message | Italien |
|---|---|
| l'objet | l'oggetto |
| le destinataire | il destinatario |
| l'expéditeur | il mittente |
| en copie | in copia (Cc) |
| en copie cachée | in copia nascosta (Ccn) |
| la pièce jointe | l'allegato |
| répondre | rispondere |
| répondre à tous | rispondere a tutti |
| transférer | inoltrare |
| la signature | la firma |

## 2. Objet et formule d'ouverture

### 2.1. L'objet (oggetto)

| Italien | Français |
|---|---|
| **Oggetto:** Richiesta di informazioni | Objet : Demande d'informations |
| **Oggetto:** Candidatura per la posizione di... | Objet : Candidature au poste de... |
| **Oggetto:** Conferma dell'appuntamento del 12 marzo | Objet : Confirmation du rendez-vous du 12 mars |
| **Oggetto:** Sollecito — fattura n. 245 | Objet : Relance — facture n° 245 |
| **Oggetto:** Invio documentazione richiesta | Objet : Envoi des documents demandés |
| **Oggetto:** Proposta di collaborazione | Objet : Proposition de collaboration |
| **Oggetto:** Convocazione riunione del 5 aprile | Objet : Convocation à la réunion du 5 avril |
| **Oggetto:** Riscontro alla Sua richiesta del 3 maggio | Objet : Réponse à votre demande du 3 mai |

### 2.2. Les formules d'appel

| Registre | Italien | Français |
|---|---|---|
| Très formel, destinataire inconnu | **Egregio Signore, / Gentile Signora,** | Monsieur, / Madame, |
| Formel, avec titre | **Egregio Dott. Bianchi,** | Monsieur Bianchi, |
| Formel, féminin | **Gentile Dott.ssa Rossi,** | Madame Rossi, |
| À une entreprise | **Spettabile Azienda, / Spett.le Ditta,** | Madame, Monsieur, (à la société) |
| Destinataire inconnu | **A chi di competenza,** | À qui de droit, |
| Semi-formel | **Gentilissimo/a,** | Cher Monsieur / Chère Madame, |
| Collègues, ton neutre | **Buongiorno Marco,** | Bonjour Marco, |
| Informel professionnel | **Ciao Laura,** | Salut Laura, |
| À plusieurs personnes | **Gentili tutti, / Buongiorno a tutti,** | Bonjour à tous, |

:::caution Faux pas fréquent
`Caro / Cara` est réservé aux relations chaleureuses déjà établies. À un client ou à un supérieur inconnu, il paraît familier : préférez `Gentile` ou `Egregio`.
:::

## 6. Modèles complets

### 6.1. Demande d'information

```
Oggetto: Richiesta di informazioni sui Vostri servizi

Gentile Dott.ssa Bianchi,

Le scrivo in merito ai servizi di consulenza presentati sul Vostro sito.
Vorrei ricevere maggiori informazioni sulle tariffe e sui tempi di
realizzazione per un progetto di media dimensione.

Le sarei grato se potesse inviarmi un preventivo dettagliato.

Resto in attesa di un Suo cortese riscontro e La ringrazio
anticipatamente.

Cordiali saluti,
Marco Rossi
```

### 6.2. Candidature

```
Oggetto: Candidatura per la posizione di Sviluppatore Backend

Spettabile Azienda,

in riferimento all'annuncio pubblicato sul Vostro sito, desidero
propormi per la posizione di Sviluppatore Backend.

Lavoro da tre anni nello sviluppo di applicazioni web e ritengo che il
mio profilo possa corrispondere alle esigenze indicate nell'annuncio.

In allegato troverete il mio curriculum vitae.

Resto a disposizione per un eventuale colloquio e porgo distinti saluti.

Laura Ferrari
```

### 6.3. Confirmation de rendez-vous

```
Oggetto: Conferma dell'incontro di giovedì 14

Buongiorno Ingegner Conti,

Le confermo il nostro incontro di giovedì 14 alle ore 10:00 presso la
nostra sede di Via Garibaldi 12.

Come concordato, porterò la documentazione tecnica aggiornata.

Qualora dovessero sorgere imprevisti, non esiti a contattarmi.

Un cordiale saluto,
Giulia Moretti
```
