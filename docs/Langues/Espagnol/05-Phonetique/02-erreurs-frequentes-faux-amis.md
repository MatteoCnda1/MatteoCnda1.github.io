# Erreurs fréquentes et faux-amis

> La proximité du français et de l'espagnol est un formidable accélérateur — et un piège permanent. Les deux langues partagent des milliers de mots, mais une partie d'entre eux a divergé de sens : annoncer *estoy embarazada* en réunion produit un effet mémorable. Cette fiche recense les faux-amis les plus dangereux, puis les fautes typiques des francophones, de la prononciation à la syntaxe.

## 1. Les faux-amis les plus dangereux

| Mot espagnol | Ce qu'on croit | Sens réel | Le mot français se dit… |
|---|---|---|---|

| **el éxito** | la sortie | **le succès** | la sortie = *la salida* |
| **largo** | large | **long** | large = *ancho* |
| **el sujeto** | le sujet (thème) | **l'individu, le type** | le sujet = *el tema, el asunto* |
| **la carpeta** | la moquette | **le dossier, la chemise** | la moquette = *la moqueta* |
| **el vaso** | le vase | **le verre** | le vase = *el jarrón* |
| **la ropa** | la robe | **les vêtements** | la robe = *el vestido* |
| **quitar** | quitter | **enlever, retirer** | quitter = *dejar, marcharse de* |
| **entender** | entendre | **comprendre** | entendre = *oír* |
| **partir** | partir | **couper, fendre, partager** | partir = *irse, marcharse, salir* |
| **subir** | subir | **monter** | subir = *sufrir, padecer* |
| **el apellido** | l'appellation | **le nom de famille** | l'appellation = *la denominación* |

| **el pie** | la pie | **le pied** | la pie = *la urraca* |

## 2. Faux-amis partiels

Ces mots existent bien dans les deux langues avec un sens commun, mais l'espagnol en a un second qui surprend.

| Mot | Sens partagé | Sens supplémentaire en espagnol |
|---|---|---|
| **la carrera** | la course | le cursus universitaire, la carrière |
| **el colegio** | le collège | l'école primaire (Espagne), l'ordre professionnel |
| **la clase** | la classe | le cours, le type/la sorte |
| **la cuestión** | la question (problème) | jamais une question posée → *la pregunta* |
| **realizar** | réaliser (faire) | jamais « se rendre compte » → *darse cuenta de* |
| **asistir a** | assister (aider) | surtout « assister à, être présent » |
| **ignorar** | ignorer (ne pas savoir) | et aussi « faire semblant de ne pas voir » |
| **soportar** | supporter (porter) | supporter/tolérer ; un fan = *un aficionado* |
| **la tapa** | le couvercle | la tapa (petite assiette) |
| **la manzana** | la pomme | le pâté de maisons |
| **la muñeca** | le poignet | la poupée |
| **la mancha** | — | la tache (*La Mancha* = la région) |
| **el tiempo** | le temps | aussi la météo, la mi-temps |
| **la planta** | la plante | l'étage |
| **el piso** | — | l'appartement ; le sol ; l'étage |

## 3. Erreurs de prononciation

| Erreur typique | Ce qu'il faut faire | Exemple |
|---|---|---|
| Nasaliser les voyelles | **Aucune nasale en espagnol** : le *n* et le *m* s'entendent | *pan* = « pann », *bien* = « biènn », *con* = « konn » |
| Prononcer *u* comme dans « lune » | *u* = « ou » | *universidad* = « ou-ni-ver-si-dad » |
| Ne pas prononcer le *e* final | toutes les voyelles se prononcent | *noche* = « no-tché », *grande* = « gran-dé » |
| Prononcer le *h* | le *h* est **toujours muet** | *hola* = « ola », *ahora* = « a-ora » |
| Faire un *j* à la française | *j* et *g* + e/i sont râclés | *jamón*, *mujer*, *gente* |
| Faire un *ch* à la française | *ch* = « tch » | *muchacho*, *coche* |
| Prononcer *s* comme [z] entre voyelles | le *s* est **toujours sourd** | *casa* = « cassa », pas « caza » |
| Confondre *r* et *rr* | *rr* est roulé et long | *pero* (mais) ≠ *perro* (chien) ; *caro* ≠ *carro* |
| Distinguer *b* et *v* | c'est **le même son** | *vaca* et *baca* se prononcent pareil |
| Dire « kou » pour *qu* | le *u* est muet | *queso* = « késo », *quince* = « kin-thé » |
| Accentuer la dernière syllabe par réflexe français | respecter l'accent tonique espagnol | *tele**fo**no* ✗ → *te**lé**fono* ✓ |
| Lire *ll* comme un « l » | *ll* = « y » | *llamar* = « yamar », *calle* = « ca-yé » |
| Oublier le *ñ* | *ñ* = « gn » | *año* (année) ≠ *ano* (anus) |

## 4. Erreurs de genre et de nombre

| Erreur | Correct | Explication |
|---|---|---|
| *la problema* | **el problema** | mots en *-ma* d'origine grecque : *el tema, el sistema, el programa, el clima, el idioma* |
| *le sang, la mer…* | attention aux genres divergents | *la sangre* (fém.), *el mar* (masc.), *la leche* (fém.), *el color* (masc.), *la nariz* (fém.) |
| *la mano* est-il masculin ? | **la mano** | féminin malgré le *-o* ; comme *la foto, la moto, la radio* |
| *el agua* serait masculin | **el agua… fría** | féminin, mais article *el* devant *a-* tonique : *el agua, el alma, el aula, el águila* |
| *los gentes* | **la gente** (singulier) | *la gente es simpática*, verbe au singulier |
| *las vacaciones* au singulier | toujours **pluriel** | comme *las gafas, las tijeras* |
| *el personas* | attention aux accords | tous les adjectifs s'accordent : *unas personas simpáticas* |
| *el árbol grandes* | **los árboles grandes** | accord en genre **et** en nombre, systématiquement |

## 5. Erreurs de verbes et de constructions

| Erreur fréquente | Correct | Pourquoi |
|---|---|---|
| *Soy 25 años* | **Tengo 25 años** | l'âge se dit avec *tener* |
| *Soy hambre / frío* | **Tengo hambre / frío** | de même : *tener sed, sueño, miedo, prisa, razón* |
| *Hace dos años que vivo* mal employé | **Llevo dos años viviendo aquí** | *llevar* + gérondif exprime la durée |
| *Yo soy contento* | **Estoy contento** | état passager → *estar* |
| *Ella está profesora* | **Es profesora** | identité, profession → *ser* |
| *Yo gusto el cine* | **Me gusta el cine** | *gustar* se construit à l'envers : le sujet est la chose aimée |
| *Yo me gusta los libros* | **Me gustan los libros** | le verbe s'accorde avec *los libros* |
| *He ido ayer* | **Fui ayer** | *ayer, la semana pasada* → *pretérito indefinido* |
| *Hoy fui al médico* | **Hoy he ido al médico** | *hoy, esta semana* → *pretérito perfecto* (Espagne) |
| *Es necesario que vienes* | **Es necesario que vengas** | subjonctif après expression de nécessité |
| *Cuando vendrás, llámame* | **Cuando vengas, llámame** | futur dans une subordonnée temporelle → subjonctif présent |
| *Espero que puedes venir* | **Espero que puedas venir** | verbe de souhait → subjonctif |
| *No he visto nada de nadie* | **No he visto nada / a nadie** | la double négation avec *no* est **normale** : *no vino nadie* |
| *Veo Juan* | **Veo a Juan** | *a* personnel obligatoire devant un COD humain déterminé |
| *Busco por un piso* | **Busco un piso** | *buscar, esperar, pedir* sont directs, sans préposition |
| *Voy a dormir me* | **Voy a dormirme** | le pronom se colle à l'infinitif, au gérondif et à l'impératif affirmatif |
| *Dame lo* | **Dámelo** | pronoms soudés, avec accent écrit si nécessaire |
| *Él se lava las suyas manos* | **Se lava las manos** | article défini, pas de possessif pour les parties du corps |

## 6. Erreurs de prépositions

| Erreur | Correct | Note |
|---|---|---|
| *Pienso a ti* | **Pienso en ti** | *pensar en* |
| *Sueño de ti* | **Sueño contigo** | *soñar con* |
| *Me acuerdo el día* | **Me acuerdo del día** | *acordarse de* |
| *Voy en España* | **Voy a España** | déplacement = *a* ; *en* = lieu où l'on est |
| *Estoy a casa* | **Estoy en casa** | — |
| *Empiezo de trabajar* | **Empiezo a trabajar** | *empezar a* |
| *Trato a hacerlo* | **Trato de hacerlo** | *tratar de* |
| *Sirve para nada / no sirve a nada* | **No sirve para nada** | *servir para* |
| *Depende el tiempo* | **Depende del tiempo** | *depender de*, toujours |
| *Salgo con casa* | **Salgo de casa** | *salir de* |
| *Entro en el coche* | **Subo al coche** | on *monte* dans un véhicule |
| *Casarse a* | **Casarse con** | — |
| *Enamorarse con* | **Enamorarse de** | — |
| *Por / para* confondus | *por* = cause, moyen, durée ; *para* = but, destination, échéance | *Lo hago **por** ti* (à cause de toi) ≠ *Lo hago **para** ti* (pour toi, destiné à toi) |

## 7. Calques du français à éviter

| Calque | Correct | Commentaire |
|---|---|---|
| *Es muy caluroso* pour « il fait chaud » | **Hace calor** | la météo avec *hacer* |
| *Hay 3 años* | **Hace 3 años** | « il y a » temporel = *hace* |
| *Estoy de acuerdo con que…* mal construit | **Estoy de acuerdo en que…** | — |
| *Todo el mundo sabe que* (correct mais lourd) | **Todo el mundo lo sabe** | pensez à reprendre par un pronom |
| *Es difícil de hacerlo* | **Es difícil hacerlo** | pas de *de* après l'adjectif impersonnel |
| *Voy a la casa de mi amigo* → lourd | **Voy a casa de mi amigo** | *casa* sans article dans cette tournure |
| *Bueno día* | **Buenos días** | pluriel figé, comme *buenas tardes, buenas noches* |
| *¿Cómo tú te llamas?* | **¿Cómo te llamas?** | inversion inutile, pronom sujet omis |
| *Yo, yo pienso que…* | **Yo creo que… / Pienso que…** | ne pas répéter le pronom sujet |
| *Muy mucho* | **Muchísimo** | *muy* ne modifie jamais *mucho* |
| *Es más mejor* | **Es mejor** | comparatifs irréguliers : *mejor, peor, mayor, menor* |
| *Tengo 25 ans* en lisant « años » à la française | prononcer **a-gnoss** | le *ñ* change tout |
| *Estoy embarazado/a* | **Estoy avergonzado / Me da vergüenza** | le classique absolu |
| *Soporto el Real Madrid* | **Soy del Real Madrid / Soy aficionado del…** | *soportar* = tolérer |
| *Realizo que…* | **Me doy cuenta de que…** | *realizar* = effectuer |
| *¿Puedo tener un café?* | **¿Me pone un café? / ¿Me da un café?** | calque de l'anglais/français |

## 8. Récapitulatif express

Les dix réflexes qui corrigent l'essentiel :

1. **Aucune voyelle nasale** — le *n* final s'entend toujours.
2. Le **h** est muet, le **u** se dit « ou », le **s** est toujours sourd.
3. *Ser* pour l'identité et les traits permanents, *estar* pour les états et les lieux.
4. L'âge, la faim, la peur, le froid : **tener**, jamais *ser*.
5. *Gustar* se construit à l'envers, et s'accorde avec la chose aimée.
6. **A personnel** devant tout COD humain déterminé.
7. La double négation (*no … nada / nadie / nunca*) est la norme.
8. Le passé composé pour l'aujourd'hui, le *pretérito indefinido* pour le passé fini.
9. Après *cuando*, *espero que*, *es necesario que* : **subjonctif**.
10. Avant d'employer un mot « qui ressemble au français », vérifier qu'il n'est pas dans la liste des faux-amis ci-dessus.
