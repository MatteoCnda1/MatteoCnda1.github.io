# Prépositions et connecteurs logiques : por / para, a, de, en

> Les prépositions ne se traduisent pas mot à mot : le français *pour* recouvre à lui seul les deux prépositions espagnoles **por** et **para**, dont la confusion est la deuxième grande difficulté de la langue après *ser / estar*. Cette fiche détaille les emplois de chaque préposition, les verbes qui en imposent une, et les connecteurs logiques qui structurent un discours ou un texte écrit.

## 1. Panorama des prépositions

Les prépositions simples de l'espagnol sont peu nombreuses :

**a, ante, bajo, con, contra, de, desde, durante, en, entre, hacia, hasta, mediante, para, por, según, sin, sobre, tras**.

| Préposition | Sens principal | Exemple |
|---|---|---|
| **a** | direction, destinataire, heure | **Voy a Madrid.** — *Je vais à Madrid.* |
| **de** | origine, possession, matière | **El coche de mi padre.** — *La voiture de mon père.* |
| **en** | lieu (dans, sur), moyen de transport | **Estoy en casa.** — *Je suis à la maison.* |
| **con** | accompagnement, moyen | **Voy con ella.** — *Je vais avec elle.* |
| **sin** | absence | **Café sin azúcar.** — *Café sans sucre.* |
| **por** | cause, passage, échange | **Gracias por todo.** — *Merci pour tout.* |
| **para** | but, destination, échéance | **Es para ti.** — *C'est pour toi.* |
| **desde** | point de départ | **Desde el lunes.** — *Depuis lundi.* |
| **hasta** | limite | **Hasta mañana.** — *À demain.* |
| **hacia** | direction approximative | **Va hacia el norte.** — *Il va vers le nord.* |
| **sobre** | sur, à propos de, environ | **Un libro sobre historia.** — *Un livre sur l'histoire.* |
| **entre** | entre, parmi | **Entre tú y yo.** — *Entre toi et moi.* |
| **según** | selon | **Según el informe.** — *Selon le rapport.* |
| **ante / bajo / tras** | devant / sous / après (littéraire) | **Ante el juez.** — *Devant le juge.* |

## 2. Por et para : la distinction fondamentale

Formule simple : **para regarde vers l'avant** (but, destination, échéance) ; **por regarde vers l'arrière ou autour** (cause, moyen, passage, échange).

### 2.1. Les emplois de PARA

| Emploi | Exemple espagnol | Traduction |
|---|---|---|
| **But, finalité** | **Estudio para aprobar el examen.** | J'étudie pour réussir l'examen. |
| **Destinataire** | **Este regalo es para ti.** | Ce cadeau est pour toi. |
| **Destination (lieu)** | **Salgo para Barcelona.** | Je pars pour Barcelone. |
| **Échéance, date limite** | **El informe es para el viernes.** | Le rapport est pour vendredi. |
| **Opinion** | **Para mí, es un error.** | Pour moi, c'est une erreur. |
| **Comparaison inattendue** | **Para ser extranjero, habla muy bien.** | Pour un étranger, il parle très bien. |
| **Usage, fonction** | **Una taza para café.** | Une tasse à café. |

### 2.2. Les emplois de POR

| Emploi | Exemple espagnol | Traduction |
|---|---|---|
| **Cause, motif** | **Lo hice por amor.** | Je l'ai fait par amour. |
| **Cause (+ nom)** | **Cerrado por vacaciones.** | Fermé pour cause de vacances. |
| **Passage, traversée** | **Paseo por el parque.** | Je me promène dans le parc. |
| **Lieu approximatif** | **Vive por el centro.** | Il habite du côté du centre. |
| **Durée** | **Estuve allí por tres días.** | J'y suis resté trois jours. |
| **Moment approximatif** | **Por la mañana estudio.** | Le matin, j'étudie. |
| **Échange, prix** | **Lo compré por diez euros.** | Je l'ai acheté (pour) dix euros. |
| **Moyen, canal** | **Te llamo por teléfono.** | Je t'appelle par téléphone. |
| **Complément d'agent (passif)** | **Escrito por Cervantes.** | Écrit par Cervantès. |
| **Substitution** | **Firmo por mi jefe.** | Je signe à la place de mon chef. |
| **Distribution, taux** | **Cien euros por persona.** | Cent euros par personne. |
| **Multiplication** | **Tres por cuatro son doce.** | Trois fois quatre font douze. |

### 2.3. Le test décisif

| Question | Réponse |
|---|---|
| « Dans quel but ? » / « Pour qui ? » / « Pour quand ? » | **para** |
| « Pourquoi ? (à cause de quoi ?) » / « Par où ? » / « En échange de quoi ? » | **por** |

Paires minimales éclairantes :

- **Lo hago por ti.** — *Je le fais à cause de toi / à ta place.* (motif)
- **Lo hago para ti.** — *Je le fais pour toi.* (destinataire, bénéficiaire)
- **Estudio por mi padre.** — *J'étudie à cause de mon père (il me pousse).*
- **Estudio para ser médico.** — *J'étudie pour devenir médecin.*
- **Viajo por España.** — *Je voyage à travers l'Espagne.*
- **Salgo para España.** — *Je pars pour l'Espagne.*

### 2.4. Expressions figées à mémoriser

| Avec **por** | Avec **para** |
|---|---|
| **por favor** (s'il vous plaît) | **para siempre** (pour toujours) |
| **por supuesto** (bien sûr) | **para nada** (pas du tout) |
| **por fin** (enfin) | **para colmo** (pour couronner le tout) |
| **por eso** (c'est pourquoi) | **estar para** (être sur le point de) |
| **por ejemplo** (par exemple) | **no estar para** (ne pas être d'humeur à) |
| **por ahora** (pour l'instant) | — |
| **por lo menos** (au moins) | — |
| **por si acaso** (au cas où) | — |
| **por cierto** (au fait) | — |
| **por lo general** (en général) | — |

## 3. La préposition a

| Emploi | Exemple | Traduction |
|---|---|---|
| Direction avec verbe de mouvement | **Voy a la playa.** | Je vais à la plage. |
| COD de personne déterminée | **Veo a mi hermana.** | Je vois ma sœur. |
| COI | **Le doy el libro a Pedro.** | Je donne le livre à Pedro. |
| Heure | **A las tres de la tarde.** | À trois heures de l'après-midi. |
| Distance | **A dos kilómetros de aquí.** | À deux kilomètres d'ici. |
| Manière | **Escrito a mano.** | Écrit à la main. |
| Prix variable | **¿A cuánto está el kilo?** | À combien est le kilo ? |
| Date (avec estar) | **Estamos a 5 de mayo.** | Nous sommes le 5 mai. |

La construction **ir a + infinitif** exprime le futur proche : **Voy a llamarte esta noche.** — *Je vais t'appeler ce soir.*

## 4. Les prépositions de, en, con, sin

### 4.1. de

| Emploi | Exemple | Traduction |
|---|---|---|
| Possession | **La casa de Ana.** | La maison d'Ana. |
| Origine | **Soy de Francia.** | Je viens de France. |
| Matière | **Una mesa de cristal.** | Une table en verre. |
| Contenu | **Un vaso de agua.** | Un verre d'eau. |
| Sujet, thème | **Hablamos de política.** | Nous parlons de politique. |
| Heure précisée | **Las ocho de la mañana.** | Huit heures du matin. |
| Cause (émotions) | **Morirse de risa.** | Mourir de rire. |

### 4.2. en

L'espagnol **en** couvre à la fois le français *dans*, *à* (lieu où l'on est) et *en*.

- **Vivo en Madrid, en un piso pequeño.** — *J'habite à Madrid, dans un petit appartement.*
- **El libro está en la mesa.** — *Le livre est sur la table.* (en espagnol, *en* peut valoir « sur »)
- **Viajo en tren / en coche / en avión.** — *Je voyage en train / en voiture / en avion.*
- Exception : **a pie** et **a caballo** (à pied, à cheval).
- **En verano hace mucho calor.** — *En été, il fait très chaud.*

:::warning Piège
Le français « aller **à** Madrid » devient **ir a Madrid**, mais « être **à** Madrid » devient **estar en Madrid**. Le mouvement prend *a*, la position prend *en*.
:::

### 4.3. con et sin

- **Café con leche, por favor.** — *Un café au lait, s'il vous plaît.*
- **Lo abrí con un cuchillo.** — *Je l'ai ouvert avec un couteau.*
- **Se fue sin decir nada.** — *Il est parti sans rien dire.* (après *sin*, on garde le mot négatif)
- Formes soudées : **conmigo, contigo, consigo**.

## 5. Desde, hasta, hacia, entre, sobre

| Préposition | Emploi | Exemple |
|---|---|---|
| **desde** | point de départ (temps ou lieu) | **Trabajo aquí desde 2020.** — *Je travaille ici depuis 2020.* |
| **desde hace** | durée écoulée | **Vivo aquí desde hace tres años.** — *J'habite ici depuis trois ans.* |
| **hasta** | limite finale | **Trabajo hasta las seis.** — *Je travaille jusqu'à six heures.* |
| **hacia** | direction approximative, environ | **Llegaré hacia las nueve.** — *J'arriverai vers neuf heures.* |
| **entre** | entre deux éléments, parmi | **Entre semana no salgo.** — *En semaine, je ne sors pas.* |
| **sobre** | sur, à propos de, environ | **Un debate sobre el clima.** — *Un débat sur le climat.* |
| **durante** | pendant | **Durante la reunión.** — *Pendant la réunion.* |
| **tras** | après, derrière | **Tras el accidente.** — *Après l'accident.* |
| **mediante** | au moyen de | **Mediante un acuerdo.** — *Au moyen d'un accord.* |

Le couple **desde… hasta** correspond à *de… à* : **Desde las nueve hasta las cinco.** — *De neuf heures à cinq heures.*

## 6. Verbes suivis d'une préposition imposée

Ces constructions sont à apprendre comme des blocs : elles divergent souvent du français.

| Verbe + préposition | Français | Exemple |
|---|---|---|
| **acordarse de** | se souvenir de | **Me acuerdo de ti.** |
| **olvidarse de** | oublier | **Me olvidé de llamarte.** |
| **depender de** | dépendre de | **Depende de ti.** |
| **darse cuenta de** | se rendre compte de | **Me di cuenta del error.** |
| **tratar de** | essayer de | **Trato de entenderlo.** |
| **dejar de** | arrêter de | **Dejé de fumar.** |
| **acabar de** | venir de (passé récent) | **Acabo de llegar.** — *Je viens d'arriver.* |
| **empezar a / comenzar a** | commencer à | **Empecé a trabajar.** |
| **aprender a** | apprendre à | **Aprendo a conducir.** |
| **ayudar a** | aider à | **Le ayudo a estudiar.** |
| **volver a** | refaire (à nouveau) | **Volví a llamarlo.** — *Je l'ai rappelé.* |
| **atreverse a** | oser | **No me atrevo a decirlo.** |
| **soñar con** | rêver de | **Sueño con viajar.** |
| **contar con** | compter sur | **Cuento contigo.** |
| **casarse con** | se marier avec | **Se casó con Ana.** |
| **pensar en** | penser à | **Pienso en ti.** |
| **confiar en** | avoir confiance en | **Confío en él.** |
| **insistir en** | insister pour | **Insiste en venir.** |
| **tardar en** | mettre du temps à | **Tardé en entenderlo.** |
| **preocuparse por** | se soucier de | **Se preocupa por todo.** |
| **luchar por** | lutter pour | **Luchan por sus derechos.** |
| **entrar en** | entrer dans | **Entró en la sala.** |

:::note Verbes sans préposition en espagnol
Certains verbes qui exigent une préposition en français n'en prennent aucune en espagnol : **buscar** (chercher — *busco un piso*, sans *de*), **esperar** (attendre), **mirar** (regarder), **escuchar** (écouter), **pedir** (demander), **pagar** (payer). *Pienso ir* = *je pense y aller*.
:::

## 7. Locutions prépositives

| Espagnol | Français |
|---|---|
| **al lado de** | à côté de |
| **cerca de / lejos de** | près de / loin de |
| **delante de / detrás de** | devant / derrière |
| **encima de / debajo de** | au-dessus de / en dessous de |
| **dentro de / fuera de** | à l'intérieur de / en dehors de |
| **enfrente de / frente a** | en face de |
| **alrededor de** | autour de |
| **a través de** | à travers |
| **junto a** | auprès de |
| **antes de / después de** | avant / après |
| **a pesar de** | malgré |
| **en lugar de / en vez de** | au lieu de |
| **además de** | en plus de |
| **acerca de** | au sujet de |
| **gracias a** | grâce à |
| **debido a** | en raison de |

- **El banco está enfrente de la estación, al lado de la farmacia.** — *La banque est en face de la gare, à côté de la pharmacie.*
- **A pesar de la lluvia, salimos a pasear.** — *Malgré la pluie, nous sommes sortis nous promener.*

## 8. Les connecteurs logiques

### 8.1. Addition et énumération

| Espagnol | Français |
|---|---|
| **y** (**e** devant i-/hi-) | et |
| **además** | de plus, en outre |
| **también** | aussi |
| **asimismo** | de même |
| **por otra parte** | d'autre part |
| **en primer lugar / por último** | premièrement / enfin |

Note : *y* devient **e** devant un mot commençant par *i-* ou *hi-* : **padre e hijo** (père et fils), **España e Italia**.

### 8.2. Opposition et concession

| Espagnol | Français |
|---|---|
| **pero** | mais |
| **sino (que)** | mais au contraire (après une négation) |
| **sin embargo / no obstante** | cependant, néanmoins |
| **aunque** | bien que, même si |
| **a pesar de que** | malgré le fait que |
| **en cambio** | en revanche |
| **mientras que** | tandis que |

Distinction **pero / sino** : *sino* corrige une négation qui précède.
- **No es rojo, sino azul.** — *Ce n'est pas rouge, mais bleu.*
- **Es caro, pero me gusta.** — *C'est cher, mais ça me plaît.*
- **No vino, sino que llamó.** — *Il n'est pas venu, mais il a appelé.* (devant un verbe conjugué : *sino que*)

### 8.3. Cause et conséquence

| Espagnol | Français |
|---|---|
| **porque** | parce que |
| **como** (en tête de phrase) | comme, puisque |
| **ya que / puesto que / dado que** | puisque, étant donné que |
| **a causa de / debido a** | à cause de / en raison de |
| **por lo tanto / por consiguiente** | par conséquent |
| **así que / de modo que** | si bien que, donc |
| **entonces** | alors |
| **por eso** | c'est pourquoi |

- **Como llovía, no salimos.** — *Comme il pleuvait, nous ne sommes pas sortis.*
- **No pude venir porque estaba enfermo, por eso te llamé.** — *Je n'ai pas pu venir parce que j'étais malade, c'est pourquoi je t'ai appelé.*

Attention : **¿por qué?** (en deux mots, avec accent) = « pourquoi ? » ; **porque** (en un mot) = « parce que » ; **el porqué** (nom) = « la raison ».

### 8.4. But, condition, temps

| Espagnol | Français | Mode requis |
|---|---|---|
| **para que** | pour que | subjonctif |
| **a fin de que** | afin que | subjonctif |
| **si** | si | indicatif ou imparfait du subjonctif |
| **a menos que / a no ser que** | à moins que | subjonctif |
| **siempre que / con tal de que** | pourvu que | subjonctif |
| **cuando** | quand | indicatif (passé) / subjonctif (futur) |
| **antes de que** | avant que | subjonctif |
| **después de que** | après que | indicatif ou subjonctif |
| **en cuanto / tan pronto como** | dès que | subjonctif si futur |
| **mientras** | pendant que / tant que | indicatif / subjonctif |

- **Te lo explico para que lo entiendas.** — *Je te l'explique pour que tu le comprennes.*
- **Cuando llegues, llámame.** — *Quand tu arriveras, appelle-moi.* (subjonctif car futur)
- **En cuanto termine, te aviso.** — *Dès que j'aurai fini, je te préviens.*

### 8.5. Reformulation et conclusion

| Espagnol | Français |
|---|---|
| **es decir / o sea** | c'est-à-dire |
| **en otras palabras** | en d'autres termes |
| **de hecho** | en fait |
| **en realidad** | en réalité |
| **en resumen / en pocas palabras** | en résumé |
| **en conclusión / para concluir** | en conclusion |
| **sobre todo** | surtout |
| **por lo visto** | apparemment |

## 9. Erreurs fréquentes

| Français | Espagnol correct | Erreur typique |
|---|---|---|
| Merci pour votre aide. | **Gracias por su ayuda.** | *gracias para* |
| Je pars pour Madrid. | **Salgo para Madrid.** | *salgo por Madrid* (= je pars à cause de Madrid) |
| Je cherche un appartement. | **Busco un piso.** | *busco de un piso* |
| Je pense à toi. | **Pienso en ti.** | *pienso a ti* |
| J'habite ici depuis 3 ans. | **Vivo aquí desde hace 3 años.** | *desde 3 años* |
| Il est entré dans la salle. | **Entró en la sala.** | *entró a la sala* (accepté en Amérique latine) |
| Je viens d'arriver. | **Acabo de llegar.** | *vengo de llegar* |
| Ce n'est pas noir mais blanc. | **No es negro, sino blanco.** | *pero blanco* |
| En voiture. | **En coche.** | *a coche* |
| Je rêve de voyager. | **Sueño con viajar.** | *sueño de viajar* |
