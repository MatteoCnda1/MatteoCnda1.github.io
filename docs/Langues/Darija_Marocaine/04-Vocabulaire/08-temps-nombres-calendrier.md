# Temps, nombres et calendrier

> Compter, donner l'heure, fixer un rendez-vous : ce sont les premières choses qu'on doit savoir faire dans une langue. Le système marocain a ses particularités — un mot spécifique pour « deux » (*jouj*), des formes courtes devant les noms comptés, deux calendriers en usage et des noms de mois empruntés au français. Cette fiche donne les nombres de 1 à 100, les unités de temps, les jours, les mois et les saisons, puis les phrases pour dire l'heure et situer une action.

| ستة | **setta** | six |
| سبعة | **seb3a** | sept |
| تمنية | **tmenya** | huit |
| تسعود | **ts3oud** | neuf |
| عشرة | **3achra** | dix |
| حداش | **7Dach** | onze |
| طناش | **Tnach** | douze |
| تلطاش | **tleTTach** | treize |
| ربعطاش | **rbe3Tach** | quatorze |
| خمسطاش | **khemsTach** | quinze |
| سطاش | **seTTach** | seize |
| سبعطاش | **sbe3Tach** | dix-sept |
| تمنطاش | **tmenTach** | dix-huit |
| تسعطاش | **tse3Tach** | dix-neuf |
| عشرين | **3achrin** | vingt |

**Formes courtes.** Devant un nom compté, les nombres de 3 à 10 perdent leur `-a` final : `tlata` → **`tlat snin`** (trois ans), `khemsa` → **`khems dyour`** (cinq maisons), `3achra` → **`3achr d nnas`** (dix personnes). Au-delà de 10, on intercale **`d`** ou **`dyal`** : `7Dach d ddirham` (onze dirhams).

## Ce qu'il faut retenir

- **`jouj`** (deux) est propre à la darija : on ne dit pas *itnayn*.
- De 3 à 10, la **forme courte** s'emploie devant un nom compté : `tlat snin`, `khems dyour`.
- Au-delà de 10, on intercale **`d`** / **`dyal`** : `7Dach d ddirham`, `3achrin dyal nnas`.
- Les jours se construisent avec **`nhar`** + nom : `nhar lkhmis` (jeudi).
- Les mois usuels sont des **emprunts au français** (`youlyouz`, `ghocht`, `chotanbir`), le calendrier hégirien servant aux fêtes.
- `chchta` signifie à la fois **l'hiver** et **la pluie** — le contexte tranche.
