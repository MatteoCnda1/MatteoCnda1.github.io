Principes(1):Protocoles
Port Aggregation Protocol (PAgP).

Propriétaire Cisco : Paquets PAgP sont echangés
entre ports compatibles pour former des EC.

Quand l’EtherChannel est formé le Spanning tree le
rajoute en tant que port unique.
Link Aggregation Control Protocol (LACP).

IEEE 802.3ad.

Fonction similaire à PAgP.

Utilisable dans les environnements mixtes (Cisco
ou Non). Dans les environnements Cisco les deux
protocoles sont supportés.

Principes(2): Modes PAgP
Mode Description
Auto Place l'interface dans un état passif de négociation (répond mais ne prend pas
d'initiative de lancer la négociation).
Desirable Place l'interface dans un état actif de négociation pour la création d 'un channel
On Force l'interface dans un channel sans PAgP.

R&T

Principes(2): Modes LACP
Mode Purpose
Passive Place le port dans un état passif de négociation (Comme auto)
Active Place le port dans un état actif de négoiciation. (Comme desirable)
On Force l' interface dans un channel sans PAgP ou LACP.
