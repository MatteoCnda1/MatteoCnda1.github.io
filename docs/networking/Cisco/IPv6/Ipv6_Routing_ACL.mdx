RIP NG
RIP Next Generation
Caractéristiques IPv4 similaires :

Vecteur de distance, rayon de 15 sauts,
découpage d’horizon et empoisonnement
inverse

Basé sur RIPv2


Préfixe IPv6, adresse IPv6 de tronçon suivant

Utilise le groupe de multicast FF02::9, groupe
qui contient tous les routeurs RIP, comme
adresse de destination pour les mises à jour RIP

Utilise UDP + IPv6 pour le transport

EIGRP pour IPv6
EIGRP pour IPv6 est un protocole vecteur distance
amélioré

Le mode opératoire est similaire à Ipv4.
Ce qui ne change pas:

Même numéro de protocole (88)

Gère une table topologique et utilise des requêtes
pour trouver des successeurs faisables.

Utilise DUAL pour calculer les successeurs
Spécifique à EIGRP pour IPv6:

route prefixes IPv6 .

nécessite l’affectation d’un RID de 32 bit (@IPv4)

Eigrp est configuré sur une interface.

L’adressage Link-local est utilisé pour établir les
adjacences.

état shutdown par défaut (no shutdown nécessaire)

Pas de résumé automatique.
