Routage OSPF à zones multiples :
Les annonces d’état de liens ou LSA sont au cœur du routage OSPF

Les LSA de type 1 : annonces de routeur

Les LSA de type 2 : annonces de réseau diffusées par un DR

Les LSA de type 3 : annonces résumées émises et propagées par des
ABR

Les LSA de type 4 : annonces résumées émises et propagées par
ASBR

Les LSA externes de type 5 : annoncent les routes externes au
domaine OSPF

L’arborescence SPF permet de déterminer les meilleurs chemins
Les routes OSPF préfixes pour OSPF dans la table :
O, O IA (OI), O E1 ou O E2.
